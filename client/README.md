## <a name="introduction">🤖 Introduction</a>
GapFinder is an analytical tool designed to bring absolute transparency to the job application process. Instead of blindly sending applications and hoping for the best, candidates can objectively compare their current resume against a specific target job description to identify the exact technical and soft skills they are missing. This repository contains the Next.js client-side application, engineered for a frictionless, authentication-free workflow that delivers immediate clarity and actionable learning roadmaps.

## <a name="features">🔋 Features</a>

👉 Frictionless Input Flow: Drag-and-drop your resume (PDF) and paste a target job description to initiate the AI analysis in under three clicks.

👉 Visual Skill Gaps: A clean, highly organized UI that strictly categorizes your current competencies into "Matches," "Partial Matches," and "Missing," preventing data overwhelm and highlighting exactly where you stand.

👉 Actionable Learning Roadmaps: Dynamically generates a prioritized, step-by-step checklist of study topics focused exclusively on your missing skills, ensuring you don't waste time reviewing what you already know.

👉 Anonymous & Fast: Completely authentication-free architecture. Get your results in under 15 seconds without the hassle of creating an account, verifying emails, or managing passwords.

👉 Frictionless Exporting: Easily take your results with you. Generate an instant, shareable UUID link to show a mentor, copy your study roadmap to your clipboard in Markdown format, or download the full dashboard as a PDF.

👉 Privacy-First Design: The UI provides total assurance that uploaded resumes are processed entirely in memory by the backend and deleted immediately, ensuring your personal contact information remains safe.

## <a name="tech-stack">⚙️ Tech Stack</a>

- **Next.js** is the React framework used for the frontend client. It handles the UI rendering, routing via the App Router, and overall application architecture for optimal performance.

- **TypeScript** provides strict static typing across the entire codebase, ensuring a robust, predictable, and bug-free development experience.

- **Tailwind CSS** provides a utility-first styling engine, allowing for the precise implementation of the brutalist, dark-themed design system and exact OKLCH color variables without writing custom CSS files.

- **Shadcn/UI** is used as the foundational component library. It provides accessible, unstyled primitives (like Cards, Accordions, and Sheets) that are customized heavily to match the application's technical aesthetic.

- **Lucide React** supplies the clean, consistent, and highly legible iconography used throughout the application interface.
